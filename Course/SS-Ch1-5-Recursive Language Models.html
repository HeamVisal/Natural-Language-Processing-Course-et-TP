Chapter 1 · Section 5

Before you begin

Source: §5 — scope and notation. Examples, labs, and practice are added teaching material.

A language model can build a long answer by solving a smaller problem repeatedly: given what has been written so far, choose the next word. This section explains that loop and the mathematical objects it acts on.

What you will learn

  • Separate a vocabulary, a possible string, and a language.
  • Represent text, images, and algebra as sequences.
  • Distinguish a next-word function from a whole-response function.
  • Trace the growing context and identify the generated continuation.

A useful study route

  • Read one worked example at a time.
  • Predict a lab’s result, then change its input.
  • Attempt the questions before revealing answers.
  • Use the final glossary to review unfamiliar symbols.
Prerequisite Review

A set is a collection: {cats, dogs} contains two different elements. A sequence has an order and can repeat elements: [cats, cats, dogs] has length 3. A function maps each allowed input to one output. The notation f: A → B says inputs come from A and outputs belong to B. For example, f(n) = n + 1 maps 2 to 3.

Sections 0–4 and 6–10 are outside this guide. The short prerequisite box and explicitly marked extensions support §5; they do not introduce full lessons from other sections.

Chapter 1 · Section 5

Vocabulary, strings, and a language

Source: §5 — opening definitions of Σ, Σ*, and ℒ. Examples, labs, and practice are added teaching material.

Think of a vocabulary as a box of building blocks. A string is an ordered row built from those blocks. A language picks out a collection of such rows.

Three objects with different jobs

The lecturer’s notation
SymbolMeaningSmall example
Σ (capital sigma)The available words or symbols.{I, like, cats, dogs}
Σ* (sigma star)All finite sequences made from Σ, meaningful or not.[cats, I, like] is allowed.
ℒ (script L)The collection of strings identified as the language.A toy ℒ might contain only [I, like, cats] and [I, like, dogs].
L⊂Σ*

The symbol ⊂ means “is a subset of” here: every string in ℒ uses symbols from Σ and so belongs to Σ*. The reverse need not hold. The star is part of the notation for all finite lengths; it is not multiplication.

Worked Example · Possible does not mean accepted

Use the toy vocabulary Σ = {I, like, cats, dogs}. Let ℒdemo = {[I, like, cats], [I, like, dogs]}. Then:

  1. [I, like, cats] has three tokens, all in Σ. It belongs to both Σ* and ℒdemo.

  2. [cats, I, like] also has three tokens from Σ. It belongs to Σ*, but not to the two-element ℒdemo.

  3. [I, like, birds] contains “birds,” which is outside this Σ. It belongs to neither set.

Extra Explanation · The empty string

Σ* includes the empty sequence, written ε (epsilon), of length 0. It contains no invalid tokens. Whether ε also belongs to ℒ depends on the chosen language; our two-sentence ℒdemo does not include it. A set may be infinite even though each individual member is finite.

The lecturer deliberately leaves “word” and “spoken” open. At this level, Σ can be an arbitrary set of symbols and ℒ a collection of observed strings. This abstraction lets us study many types of data using the same language.

Why this distinction matters

A model can output tokens that are individually allowed while putting them in an unwanted order. To judge the result, we need a criterion beyond “every token exists in the vocabulary.” The source’s ℒ describes the language under observation; a real task must make its acceptance or quality criteria more precise.

Common Mistake

Do not confuse a vocabulary element with a whole string. “cats” can be one element of Σ; [cats, cats] is a length-2 sequence in Σ*. Repetition changes the string even though it does not add a new vocabulary element.

Added private-study practice, not an official lecturer examination. Try each question before opening its answer.

1. For Σ = {a, b}, is [a, b, a] in Σ*? What is its length?
Yes. Every token belongs to Σ, and the sequence has length 3. Repetition is allowed.
2. True or false: every string in Σ* must make sense.
False. Σ* includes all finite sequences from the vocabulary, including meaningless orders. The source explicitly includes strings that do not make sense.
3. Does ε belong to our ℒdemo? Does it belong to Σ*?
It is not one of our two accepted toy sentences, so it is outside ℒdemo. It is in Σ*: its length is zero.
4. Is [I, like] a member of ℒdemo, or merely a possible prefix?
It is a possible prefix of both accepted sentences and a member of Σ*, but it is not itself a member of the two-element ℒdemo. A prefix is an initial part of a sequence.

Chapter 1 · Section 5

Text depends on its representation

Source: §5 — Examples 1 and 2 — Khmer and English. Examples, labs, and practice are added teaching material.

The same text can be split into different kinds of units. The chosen units determine the vocabulary and the length of each sequence.

Source Example 1 · Khmer documents

The lecturer takes Σ to be the collection of Khmer words and ℒ to include the Khmer documents or utterances observed. A document can contain many everyday sentences; mathematically, the whole document can still be treated as one finite string.

The word boundaries must be decided before a document becomes a sequence of words. The source does not specify a segmentation algorithm. In particular, the simple English space-splitting exercise below should not be treated as a general Khmer word tokenizer.

Source Example 2 · English words or letters

At the word level, “I Like Cats” becomes [I, Like, Cats]: 3 tokens. Alternatively, the lecturer chooses Σ′ = {A, B, …, Z}, where the prime (′) labels a different vocabulary. Uppercasing the text and removing spaces gives [I, L, I, K, E, C, A, T, S]: 9 tokens. Here I contributes 1, LIKE contributes 4, and CATS contributes 4; 1 + 4 + 4 = 9.

A token is the unit chosen for the representation. In the letter representation, a token is one letter, even though the lecturer’s general definition uses the word “word.” The model’s next output therefore depends on the representation: one next word and one next letter are different tasks.

Source clarification · “The same information”

The source says the word and letter representations contain the same information. That needs an encoding qualification: its uppercase A–Z example discards spaces and case. For instance, “AN ICE” and “A NICE” both become ANICE, so the original boundary cannot always be recovered. A reversible character encoding that preserves separators, case, and other needed symbols can preserve the original text. The source’s central idea—different symbol choices produce different sequences—still holds.

Before defining a next-token function, decide what one output represents. A word-level function might return “Cats”; a letter-level function might return C. Both operate on sequences, but their input lengths, vocabularies, and required number of generation steps differ. The abstract framework does not tell us which representation is best for a particular task.

Chapter 1 · Section 5

Images and algebra are languages too

Source: §5 — Examples 3 and 4, including the pixel figure. Examples, labs, and practice are added teaching material.

The framework becomes more useful when “language” means any collection of symbol sequences. The next two source examples move beyond human speech.

Source Example 3 · A grayscale image is a string

Use the source’s 8-bit grayscale convention: each pixel is an integer from 0 to 255, with 0 black and 255 white. Thus the vocabulary can be Σ = {0, 1, …, 255}. Choose a scan order, such as left to right across each row, starting at the top. Reading pixels in that order turns an image into a finite sequence.

Worked Example: height 5 × width 5 = 25 pixels. The first row contributes five 225s. The second contributes [225, 225, 40, 225, 225]. The third contributes [225, 40, 40, 40, 225]. Concatenating all five rows produces one length-25 “sentence.” The line breaks above just help you check the scan.

Extra Explanation · Keep the shape and order

A bare list of 25 values does not say whether the image is 5 × 5 or 1 × 25. To reconstruct the original arrangement, the decoder needs its dimensions and scan order. Also, 0–255 integer pixels describe this chosen format; images can use other formats.

Source Example 4 · Algebra as a language

Σ = {0, 1, 2, …, x, x², …, +, −, =, (, )}

The braces describe available symbols; the ellipses (…) mean the list continues. In the lecturer’s chosen vocabulary, x² can be a token rather than three separate characters. The expression x⁷ − x can likewise be represented by [x⁷, −, x]. Joining symbols does not itself decide whether the result is meaningful or true.

(1+x)(1−x)=1−x2

Here x is a variable; x² means x × x; + and − are addition and subtraction; adjacent parenthesized factors are multiplied; = asserts equality. A string such as this identity is a candidate member of an algebraic language.

Worked Example · Check the identity

Distribute multiplication: (1 + x)(1 − x) = 1×1 + 1×(−x) + x×1 + x×(−x) = 1 − x + x − x² = 1 − x². The middle terms cancel, so this holds for every real x. For x = 2, the left side is (1 + 2)(1 − 2) = 3×(−1) = −3. The right side is 1 − 2² = 1 − 4 = −3.

Source clarification · What counts as a “correct formula”?

The source calls ℒ a language of “correct formulae” without fixing the criterion. A well-formed expression follows syntax rules; a true identity is an equality holding for every allowed variable value. These are different tests. x⁷ − x is a well-formed expression, but does not by itself assert an equality. x² = x is well formed yet fails as an identity over real numbers: at x = 2, 4 ≠ 2. A language definition must say which criterion it uses.

The numeric substitution illustrates the source identity; the expansion establishes it for all real x. One successful test value alone would not prove an identity. These examples show why a token vocabulary alone cannot supply the rules or truth conditions of a language.

Check Your Understanding · Images and algebra

Added private-study practice, not an official lecturer examination. Try each question before opening its answer.

9. How many pixel tokens does a 4 × 6 grayscale image produce using one token per pixel?
4 × 6 = 24 tokens. Shape and scan order are still needed to reconstruct the arrangement.
10. In the source image, is the plus sign darker or lighter than the background?
Darker. The plus uses value 40; the background uses 225. In this convention lower values are darker.
11. At x = 3, calculate both sides of (1 + x)(1 − x) = 1 − x².
Left: (1 + 3)(1 − 3) = 4×(−2) = −8. Right: 1 − 3² = 1 − 9 = −8. The general expansion, rather than this one test alone, proves the identity.
12. True or false: a well-formed equation must be a true identity.
False. x² = x follows ordinary syntax, but at x = 2 its sides are 4 and 2. Syntax and truth are separate criteria.

Chapter 1 · Section 5

One next token, or a whole response?

Source: §5 — definitions of M and m and the feedback diagram. Examples, labs, and practice are added teaching material.

The lecturer describes a language model as something that produces sentences and can consume one sentence and respond with another. Two function types capture two different scales of this task.

M:Σ*→Σ*

Capital M takes a finite input string and returns a finite output string. For example, an input could be [We, study] and a possible response [NLP, today]. The arrow describes the kind of output, not how that output is calculated.

m:Σ*→Σ

Lowercase m takes the entire current input string and returns one token. The source writes a word-level model, but the same type applies when the tokens are letters or pixel values. Repeated applications of m can be assembled into the larger operation M.

The source’s “We study” illustration

Worked Example · One call

m(S0)=wandS1=S0w

S0 is the starting sequence, w is the predicted token, and S1 is the new context. Writing S0w means concatenation: put w at the end. This juxtaposition is not multiplication.

Take S0 = [We, study] and w = NLP. Then S1 = [We, study, NLP]. Its length is 2 + 1 = 3 tokens. The old tokens are kept in their original order.

Key Idea

Each call predicts one new token from the current full context. Appending that token changes the input to the next call. Merely running m repeatedly on the unchanged S0 would not implement the lecturer’s feedback process.

Common Mistake · A type is not a quality guarantee

M: Σ* → Σ* allows every finite output string. It does not mathematically guarantee that the output belongs to ℒ, is grammatical, is true, or is a helpful answer. Those are intended behaviors requiring additional constraints or learning. Section 5 specifies the sequence process, not a training method.

Check Your Understanding · Two function types

Added private-study practice, not an official lecturer examination. Try each question before opening its answer.

13. For a letter vocabulary {A, B}, can m return [A, B] as two tokens in one call?
No. m returns one element of Σ: A or B. A whole two-token string is an output type allowed for M.
14. Let S₀ = [I, like] and m(S₀) = cats. Write S₁ and its length.
S₁ = [I, like, cats], with length 3. The predicted token was appended to the two-token input.
15. Does the signature M: Σ* → Σ* imply that M always gives a meaningful answer?
No. It only describes allowed input and output types. Membership in a desired language or other quality criteria requires more.
16. Why must the second model call use S₁ rather than S₀?
The source feeds the extended sequence back into m. S₁ contains the first prediction, so the next choice can depend on what has already been generated.

Chapter 1 · Section 5

Build a response one token at a time

Source: §5 — recursive construction and the equation for M(S₀). Examples, labs, and practice are added teaching material.

“Recursive” here means feeding the growing result back into the next step. A small next-token operation is repeated to build a larger finite output.

Follow the recurrence

  1. Begin with a finite context S0.

  2. Compute w = m(S0) and append it: S1 = S0w.

  3. Compute w′ = m(S1) and append it: S2 = S1w′.

  4. Continue for the chosen finite number of steps. The newly generated tokens form the response.

M(S0)=ww′⋯w(n)=S′

This is the lecturer’s notation: w, w′, … label successive predicted words; the superscript (n) is a token label here, not a power. S′ is the resulting generated string. The equation displays the continuation, not the starting context S0.

Extra Explanation · Consistent step counting

To avoid counting ambiguity in the source’s w, w′, … labels, use w₁ through wₙ for exactly n predictions. For k = 0, 1, …, n − 1, let wk+1 = m(Sk) and Sk+1 = Sk · wk+1. The dot explicitly means “append.” Then Mn(S0) = w₁ · … · wₙ and Sn = S0 · Mn(S0). The subscript n makes the chosen finite step count explicit.

Worked Example · Context versus continuation

Suppose an added toy rule gives m([I]) = like and m([I, like]) = cats. Begin at S0 = [I].

Two content-token predictions
StepInput to mPredictionNew context
1[I]like[I, like]
2[I, like]cats[I, like, cats]

The continuation is [like, cats], of length 2. The full context is [I, like, cats], of length 1 + 2 = 3. Thus M2([I]) = [like, cats], while S2 includes the original I.

When does the process stop?

The source says to repeat a finite number of times; it does not define an end token or a stopping algorithm. Without a chosen limit or another stopping condition, a next-token function can keep producing symbols indefinitely.

Extra Explanation: the lab adds an <END> control token and a maximum number of appended content tokens. Its model has extended vocabulary Σext = Σ ∪ {<END>}, where ∪ means set union. On <END>, the controller stops and leaves the marker out of the displayed text. This is an explicit extra convention; it changes the source’s bare m: Σ* → Σ setup to allow a stop signal.

The cap counts appended tokens, not model calls. Starting at I, the lookup rule appends like and cats, then makes a third call returning END. With cap 2, it stops at the cap before making that third call. The repeating rule illustrates why a finite limit matters.

What the lab teaches about the formal model

With the lookup rule, start at I and run with cap 5: two content tokens are appended and the third model call returns <END>. The final full context is in ℒdemo. Starting instead at [like, I] returns <END> immediately; the input remains outside ℒdemo. Stopping does not fix a bad sequence.

The deterministic lookup chooses cats from [I, like]; it does not reach the dogs sentence from that same input. A language can contain more strings than a particular deterministic rule generates. The repeating rule can also pass through a valid sentence and then append more tokens, moving outside our two-string language.

Terminology boundary

This section’s recursive construction describes repeated next-token feedback. It does not specify a recurrent neural network architecture, a call-stack implementation, probabilities, or a training algorithm. Those are separate choices; the lecturer covers later architectures in other sections.

17. A prompt has 4 tokens. After 3 ordinary one-token appends, how long is the full context?
4 + 3 = 7 tokens. The continuation has length 3. Appending keeps the original prompt.

Chapter 1 · Section 5

Review and keep the distinctions clear

Source: §5 — complete selected §5. Examples, labs, and practice are added teaching material.

Quick Summary

  • Choose the units: Σ may contain words, letters, pixel intensities, or algebraic symbols.
  • Separate possibility from membership: Σ* contains all finite combinations; ℒ is the chosen language.
  • Read the function types: m returns one token; M returns a string.
  • Preserve the growing context: predict from Sₖ, append, then feed Sₖ₊₁ back in.
  • Separate output from input: M(S₀) in the source is the generated continuation. The full final context also contains S₀.
  • Specify the missing choices: representation, desired language, next-token rule, and finite stopping rule all matter.

Glossary

Vocabulary · Σ
The set of symbols available to a representation.
Token
One selected symbol or unit, such as a word, letter, or pixel value.
String / sequence
An ordered finite list of tokens; repetitions are allowed.
Σ*
All finite strings over Σ, including ε.
Language · ℒ
A chosen collection of strings over the vocabulary.
Empty string · ε
The sequence containing zero tokens.
Prefix / context · Sₖ
The string available as input at a particular step.
Concatenation
Joining sequences in order; appending a token is a special case.
Next-token function · m
A function from a finite context to one vocabulary element.
Response function · M
A function from an input string to an output string.
Continuation · S′
Only the newly generated output tokens in the source equation.
Recursive generation
Predict, append, then use the longer string as the next input.
Serialization
Writing structured data as a sequence using a specified order.
Identity
An equality that holds for every allowed variable value.
Stop token · <END>
An added control convention for ending generation; not defined in the source §5.
Token budget
An added upper bound on how many content tokens the lab appends.
