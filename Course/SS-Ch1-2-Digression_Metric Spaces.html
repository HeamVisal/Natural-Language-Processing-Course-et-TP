Prerequisite Review

A set is a collection of objects. The symbol x ∈ X means “x belongs to X.” A point (a₁, a₂) is an ordered pair of coordinates. ℝ means the real numbers; ℝⁿ means lists of n real coordinates. A function f takes an input x and returns a value f(x).

Absolute value |u| is the nonnegative size of u: |−3| = |3| = 3. A square removes a minus sign: (−3)² = 9. A square root reverses squaring for nonnegative values: √9 = 3. The symbol ≤ allows equality, while < does not.

01

Start with numbers and coordinates

Measuring distance

Source: §2 — Digression: Metric Spaces, real-number, Euclidean, taxicab, and p-distances.

A distance turns “close” and “far” into a number. Before measuring, decide what the objects are and which rule fits the comparison you want to make.

On a number line: remove the direction

From −2 to 3 is a change of 5, while from 3 to −2 is a change of −5. Distance should not become negative when you reverse direction, so use an absolute value.

d(a,b)=|a−b|

Here a and b are real numbers, and d(a, b) is their distance. With a = −2 and b = 3, |a − b| = |−2 − 3| = |−5| = 5. Swapping the inputs gives |3 − (−2)| = |5| = 5. This is useful for measuring a scalar error, such as the gap between a prediction and a target.

In a plane: use the Pythagorean theorem

Let A = (a₁, a₂) and B = (b₁, b₂). The horizontal and vertical gaps form the two shorter sides of a right triangle. The straight-line distance is the length of the hypotenuse.

d2(A,B)=(a1−b1)2+(a2−b2)2
SymbolMeaning
A, BThe two points being compared.
a₁, b₁First coordinates, usually horizontal positions.
a₂, b₂Second coordinates, usually vertical positions.
d₂(A, B)Euclidean distance. The subscript 2 names the rule; it does not mean “distance squared.”
√ and the squaresSquare the coordinate differences, add them, then take the nonnegative square root.

Worked Example · The 3–4–5 triangle

Take A = (0, 0) and B = (3, 4).

  1. Calculate coordinate changes.
    a₁ − b₁ = 0 − 3 = −3
    a₂ − b₂ = 0 − 4 = −4
  2. Square and add.
    (−3)² + (−4)² = 9 + 16 = 25
  3. Take a square root.
    d₂(A, B) = √25 = 5

    The straight-line separation is 5 units. The number 25 is the squared distance, not the distance itself.

More coordinates, the same pattern

For A = (a₁, …, aₙ) and B = (b₁, …, bₙ) in ℝⁿ, add one squared difference per coordinate.

d2(A,B)=∑i=1n(ai−bi)2

The summation symbol ∑ means “add all these terms.” The index i runs from 1 to n. For A = (1, 2, 3) and B = (1, 5, 7), the differences are (0, −3, −4), so d₂ = √(0² + (−3)² + (−4)²) = 5. Extra coordinates are just extra terms; you do not need to draw the space to use the formula.

The route matters: taxicab distance

The lecturer asks us to imagine an app for tuk-tuk trips on a grid of streets. A driver moves along streets rather than through buildings. In an ideal unobstructed grid, add the total horizontal and vertical changes:

d1(A,B)=|a1−b1|+|a2−b2|

With the same A = (0, 0) and B = (3, 4), d₁ = |−3| + |−4| = 3 + 4 = 7. Both 5 and 7 are correct: they answer different distance questions. The source’s street illustration uses gaps of 4 and 3, giving the same two totals.

Beginner Tip · A model has limits

Taxicab distance models an ideal grid with usable horizontal and vertical routes. Real travel distance may depend on blocked streets, one-way rules, bridges, and road layout. This mathematical example does not claim to be a complete routing app.

A family of rules: dₚ

dp(A,B)=(|a1−b1|p+|a2−b2|p)1p,p≥1

The parameter p is a real number at least 1. The exponent 1/p takes a p-th root. At p = 1 the expression becomes taxicab distance; at p = 2 it becomes Euclidean distance. These are different metrics on the same points. The source states that all finite p ≥ 1 satisfy the metric conditions introduced next.

For our coordinate gaps 3 and 4, p = 3 gives (3³ + 4³)1/3 = (27 + 64)1/3 = 911/3 ≈ 4.49794. All terms use absolute differences before taking general powers.

02

A distance needs reliable behavior

What makes a metric?

Source: §2, the metric conditions, their interpretation, and the first two Euclidean proofs.

A metric is a distance rule with three conditions. A metric space is the pair (X, d): the objects X together with their distance rule d.

The objects need not be physical locations. X might contain numbers, coordinate vectors, or functions. The rule accepts any two objects from X and returns a finite, nonnegative real number.

d:X×X→[0,∞)

The symbol X × X means the collection of ordered pairs of objects, not a multiplication you must calculate. The interval [0, ∞) means nonnegative finite real values; ∞ itself is not included. All the conditions below must hold for every x, y, and z in X, not just one convenient example.

1. Nonnegative, and zero only for the same object

d(x,y)≥0;d(x,y)=0⇔x=y

The symbol ⇔ means “if and only if.” There are two directions: equal objects have distance 0, and distance 0 means the objects are equal. Distinct objects must have strictly positive distance.

Example: on the real line, d(2, 5) = 3 > 0 and d(2, 2) = 0. A rule that assigns zero to every pair fails, because d(2, 5) would be 0 even though 2 ≠ 5.

2. Symmetry: reversing the comparison changes nothing

d(x,y)=d(y,x)

Going from x to y and from y to x gives the same distance. The ordered inputs may be swapped without changing the result.

Example: |2 − 5| = |5 − 2| = 3. A directed travel cost can be useful, but if reversing a trip changes that cost, it is not a metric on those objects.

3. Triangle inequality: a detour cannot be shorter

d(x,y)≤d(x,z)+d(z,y)

Choose a third object z. The direct distance from x to y is no greater than the sum of the two distances through z.

Example: on the number line, x = 0, z = 1, and y = 2 give 2 ≤ 1 + 1. Equality holds. If z = 3 instead, the comparison is 2 ≤ 3 + 1 = 4.

Source wording clarification · Equality is allowed

The lecturer describes a detour as increasing the travel path. The precise statement is that it cannot decrease the distance: it can have the same length. The symbol ≤ in the source formula already allows this. A point z between x and y on a straight segment gives an equality example.

Why Euclidean distance satisfies the first two conditions

The source supplies these arguments. We unpack them so the algebra and the logic are easier to follow.

Nonnegativity

Each squared coordinate difference is ≥ 0. Their sum is ≥ 0, so its nonnegative square root is ≥ 0. In our 3–4–5 example, 9 + 16 = 25 ≥ 0 and √25 = 5 ≥ 0.

Zero exactly when A = B

If d₂(A, B) = 0, then (a₁ − b₁)² + (a₂ − b₂)² = 0. Nonnegative numbers can add to zero only if every term is zero. Therefore a₁ = b₁ and a₂ = b₂: the points are identical. Conversely, identical coordinates make both differences zero, so the distance is zero. This proves both directions of “if and only if.”

Symmetry

Reversing a coordinate difference changes its sign, but not its square: (a₁ − b₁)² = (b₁ − a₁)², and the same holds for the second coordinate. Adding and taking square roots therefore gives d₂(A, B) = d₂(B, A).

The same arguments work for n coordinates. The general Euclidean triangle-inequality proof is omitted by the lecturer. The next lab illustrates it; numerical examples alone are not a proof for all points.

A tempting rule that fails: squared Euclidean distance

Squared distance often appears in calculations, but it is not generally a metric. On the real line, let A = 0, B = 1, and C = 2. The squared direct distance from A to C is 4. The squared distances along A → B → C add to 1 + 1 = 2. The required comparison 4 ≤ 2 is false.

Extra Explanation · The restriction p ≥ 1 matters

If you try the same p-distance formula with p = 1/2, let A = (0, 0), B = (1, 1), and C = (1, 0). The direct result is (√1 + √1)² = 4, while the two detour results are 1 and 1. Again 4 ≤ 2 fails. This is a counterexample, not a new distance formula recommended by the source.

Check Your Understanding · Metric conditions

Added practice · A single counterexample can disqualify a rule.

5. Can a metric give d(x, y) = 0 when x and y are different?
No. A metric requires d(x, y) = 0 if and only if x = y. A nonnegative symmetric rule still fails to be a metric if it cannot distinguish distinct objects.
6. Why does squared distance fail for 0, 1, and 2?
For the trip from 0 to 2 through 1, the squared direct value is (0 − 2)² = 4, while the sum via 1 is (0 − 1)² + (1 − 2)² = 2. The triangle inequality would require 4 ≤ 2.
7. A rule gives d(A, B) = 3 and d(B, A) = 4. Which condition fails?
Symmetry. The values must be equal when the inputs are reversed. Such a directional cost may be useful, but it is not a metric on A and B.

03

The objects are now whole functions

Distance between functions

Source: §2, C[−1, 1], the largest-gap distance, and vector-valued outputs.

A function can be treated as one object. To compare two such objects, compare their outputs at the same input, then combine those gaps into a single distance.

This matters for approximation. A model may give a function g while the desired behavior is f. Saying “g is close to f” requires a rule for measuring their disagreement over a whole domain, not just at one hand-picked input.

Prerequisite Review · Continuous functions

A continuous function has no jump at a point: nearby inputs give outputs that approach the output at that point. A continuous graph may still have a corner. The source’s notation C[−1, 1] means all continuous real-valued functions defined on the complete closed interval from −1 to 1, including both endpoints.

C[−1,1]={f:[−1,1]→ℝ|f is continuous}

The letter C names this collection. Examples include f(x) = x, f(x) = x², and f(x) = 0 on that interval. The set contains infinitely many functions; one function includes its values at every input in the interval.

The largest vertical gap: uniform distance

d∞(f,g)=maxx∈[−1,1]|f(x)−g(x)|

At each x, calculate the absolute gap |f(x) − g(x)|. The subscript ∞ identifies this uniform distance, also called a maximum-gap distance here. It does not mean the answer is infinite. The maximum is a finite number for continuous functions on this closed interval.

Part of the equationMeaning
f, gThe two entire functions being compared.
x ∈ [−1, 1]Try every input in the chosen interval, including its endpoints.
|f(x) − g(x)|The absolute difference of the two outputs at that same x.
maxTake the largest of those gaps.
d∞(f, g)One number summarizing the worst output disagreement anywhere in the interval.
Common Mistake · Not the shortest distance between curves

Compare f(x) and g(x) at the same input. Do not look for the closest pair of points with different x-values. Two graphs can cross at one point and still have positive uniform distance because they differ elsewhere.

Worked Example · Compare a quadratic with a shifted version

f(x)=x2,g(x)=x2+12x+14
  1. Subtract the outputs.
    g(x) − f(x) = (x² + 0.5x + 0.25) − x² = 0.5x + 0.25
  2. Check the absolute gaps at the endpoints.
    At x = −1: |−0.5 + 0.25| = 0.25
    At x = 1: |0.5 + 0.25| = 0.75
  3. Find the maximum over the whole interval.

    The absolute value of this straight-line difference has no larger value between the endpoints. Therefore d∞(f, g) = 0.75.

For comparison, x = −0.5 gives a gap of 0 because the curves cross there. That does not make the two functions identical. Uniform distance 0.75 means every output gap is at most 0.75, and a gap of 0.75 is actually reached.

Extra Explanation · Why the lab’s maximum is exact

For |x| ≤ 1, |ax + b| ≤ |a||x| + |b| ≤ |a| + |b|. If a and b have the same sign, x = 1 attains this bound. If their signs differ, x = −1 does. If a or b is zero, an endpoint still attains it. Thus the bound really is a maximum; no hidden point between the samples can give a larger gap.

Why this rule is a metric

All gaps are nonnegative. The maximum is 0 exactly when f(x) = g(x) at every x, so the functions are the same. Symmetry follows because |f(x) − g(x)| = |g(x) − f(x)|.

Extra Explanation · Triangle inequality for functions

Take a third function h. At every input x, the ordinary absolute-value triangle inequality gives:

|f(x)−g(x)|≤|f(x)−h(x)|+|h(x)−g(x)|

Each term on the right is at most its own maximum. Therefore every left-hand gap is at most d∞(f, h) + d∞(h, g). Its maximum has the same bound: d∞(f, g) ≤ d∞(f, h) + d∞(h, g).

For a numerical check, let f = 0, h = 1, and g = 3 be constant functions. Then d∞(f, g) = 3 and the detour is 1 + 2 = 3.

More general domains and vector-valued outputs

d∞(f,g)=maxx∈X‖f(x)−g(x)‖

Now X is an input domain, and f(x) and g(x) may be vectors with n real entries. The notation ‖f(x) − g(x)‖ means the length of their output-difference vector; use the Euclidean norm for the examples here. The lecturer writes C(X) for the continuous functions under discussion. To make the output type explicit, one can write C(X, ℝⁿ).

Example: take X = [−1, 1], f(x) = (x, 0), and g(x) = (x + 3, 4). At every x the difference is (−3, −4), whose norm is √(9 + 16) = 5. Its maximum is therefore 5. The same point-distance formula now measures differences of function outputs.

Source assumption clarification · When does “max” exist?

The source says X is a “nice subset.” A sufficient precise assumption here is that X is nonempty and compact, for example a closed interval or closed box, and the functions are continuous. Then the gap has a finite attained maximum.

On X = (0, 1), f(x) = x and g(x) = 0 have gaps approaching 1 but no largest gap attained inside X. On all of ℝ, those same gaps are unbounded. The displayed max formula cannot be applied unchanged to every arbitrary domain. A supremum can replace a maximum for suitable bounded functions, but that is an extra extension, not the setting used in these labs.

Check Your Understanding · Uniform distance

Added practice · Compare outputs at the same input.

9. If two continuous graphs cross, must their uniform distance be 0?
No. A crossing gives a zero gap at one input. Uniform distance is the largest gap over all inputs. It is 0 only when the functions agree everywhere on the domain.
10. What is d∞ for f(x) = x² and g(x) = x² + 0.5x + 0.25 on [−1, 1]?

11. If d∞(f, g) = 0.1, what can you say at every input?
For every x in the domain, |f(x) − g(x)| ≤ 0.1. The uniform distance gives a worst-case bound, rather than a statement about only an average input.
12. For f(x) = (x, 0) and g(x) = (x + 3, 4), why is d∞ equal to 5?
The output difference is always (−3, −4). Its Euclidean norm is √(3² + 4²) = 5 at every input, so the maximum is also 5.

04

A different meaning of “close”

Average gap & area

Source: §2, normalized area between curves and its generalization.

Uniform distance asks for the worst gap. An average-gap distance combines the gaps across the domain and divides by the domain’s size.

Prerequisite Review · An integral as accumulated area

The integral symbol ∫ adds up contributions across an interval. For the nonnegative function |f(x) − g(x)|, it gives the geometric area between the two curves. You do not need integration techniques to understand the rectangular and triangular examples here. The dx says we are accumulating along the input coordinate x.

Why the source divides by 2

d1(f,g)=12∫−11|f(x)−g(x)| dx

The interval [−1, 1] has length 1 − (−1) = 2. Its reciprocal is 1/2. Multiplying the accumulated area by 1/2 turns it into an average absolute output gap. Here f and g are continuous real-valued functions on this interval.

If f(x) = 0 and g(x) = 3 everywhere, the gap has height 3 over a width of 2. The area is 2×3 = 6. The distance is 6/2 = 3, not 6. Both uniform and average distances equal 3 in this constant-gap case.

Notation note · The same d₁, different objects

The source uses d₁ both for taxicab distance between points and for this normalized integral distance between functions. Read the arguments: d₁(A, B) uses coordinate differences; d₁(f, g) uses output gaps across a domain. The formulas are related ways of adding absolute differences, but you must use the formula for the objects in front of you.

Worked Example · Two triangles give an average gap

Let f(x) = 0 and g(x) = x on [−1, 1]. The absolute gap is |x|, which makes a V-shaped graph.

  1. Find the left triangular area.

    From x = −1 to x = 0, the base is 1 and the height is 1. Its area is (1×1)/2 = 0.5.

  2. Find the right triangular area.

    From x = 0 to x = 1, the same calculation gives 0.5.

  3. Add, then divide by the domain length.
    Total area = 0.5 + 0.5 = 1
    Average gap = 1 / 2 = 0.5
d1(f,g)=12∫−11|x| dx=12(12+12)=12

The largest gap is 1, reached at x = −1 and x = 1. Thus the same functions have d₁ = 0.5 and d∞ = 1. Neither answer is wrong; one summarizes the average and the other the worst case.

Common Mistake · Do not cancel positive and negative errors

The signed integral of x over [−1, 1] is 0 because its negative and positive regions cancel. That is not the distance. The formula integrates |x|, so both regions contribute positively. Functions that differ must not be declared identical just because their signed errors cancel.

A narrow spike: average error can hide a large peak

The following added family keeps all functions continuous. Let f(x) = 0 and let g be a triangular spike centered at 0:

g(x)=Hmax(1−|x|w,0)

H ≥ 0 is the peak height. The half-width w satisfies 0 < w ≤ 1, so the spike stays inside [−1, 1]. At x = 0 the value is H. At x = ±w it reaches 0, and outside that interval it stays 0. A corner does not prevent continuity.

Base width = 2w
Shaded area = (base × height) / 2 = (2w × H) / 2 = Hw
Average gap d₁ = area / 2 = Hw/2
Largest gap d∞ = H

For H = 1 and w = 0.25, the area is 0.25 and d₁ = 0.125, while d∞ = 1. Reducing w makes the average gap smaller without reducing the peak. This is useful when deciding whether an error measure should prioritize overall agreement or the worst error anywhere.

Why average gap is a metric on C[−1, 1]

Absolute values and integrals of nonnegative functions give nonnegative results, and reversing f and g leaves the absolute gap unchanged. If the functions are identical, the area is zero.

For the converse, if two continuous functions differ at even one point, their positive gap persists over a small interval, possibly one-sided at an endpoint. That creates positive area. So zero average gap forces equality everywhere. Finally, integrate the pointwise triangle inequality from the previous part and divide by 2; this gives d₁(f, g) ≤ d₁(f, h) + d₁(h, g).

Extra Explanation · Why the continuity restriction matters

A function that is 1 at x = 0 and 0 everywhere else differs from the zero function at one point, but that isolated point adds no area. Their integral gap is 0. That function is not continuous, so it is not a counterexample inside C[−1, 1]. For arbitrary functions, an integral gap may fail to distinguish functions that differ only on sets of zero measure.

The source’s general normalized formula

d1(f,g)=1area(X)∫X‖f(x)−g(x)‖ dx

X is the input region; f(x) and g(x) are scalar or vector outputs; ‖·‖ measures the size of their difference. The integral accumulates that nonnegative gap over X. The denominator is the size of X: length in one dimension, area in two dimensions, and volume in higher dimensions. The source calls it “area(X)” for all cases.

For X = [−1, 1] its size is 2, recovering the earlier factor 1/2. On a two-dimensional rectangle of area 6 with a constant output gap 2, the accumulated gap is 6×2 = 12, so the normalized distance is 12/6 = 2. The vector-valued constant gap (−3, −4) has norm 5, so its normalized average is 5 on any such region.

Source assumption clarification · “Area(X)” needs care

Use the general average formula here for a closed box with positive side lengths, with continuous functions and ordinary length/area/volume. The size is finite and positive, and a nonzero continuous gap occupies positive volume. An arbitrary subset X need not have these properties; positive total area alone does not always make this a metric on all continuous functions.

Extra Explanation · A precise counterexample for an arbitrary X

Let X = [−1, 1] ∪ {2}, with ordinary length 2. Take g = 0 everywhere, and define f = 0 on [−1, 1] but f(2) = 1. Both functions are continuous relative to X because the point 2 is isolated. Yet their integral gap is 0: a single isolated point has zero length. Thus the normalized integral cannot distinguish them on this X. The simple box domains used in this guide avoid this issue.

Check Your Understanding · Average gap

Added practice · Separate a raw area from its normalized average.

13. Why does f = 0 and g(x) = x give d₁ = 0.5 rather than 0 or 1?
The absolute gap |x| has total area 1. Its positive and negative sides do not cancel because of the absolute value. Divide by interval length 2 to get 0.5. The number 1 is both the raw area and the maximum gap in this particular example, not the normalized average.
14. A spike has H = 2 and w = 0.2. What is its average-gap distance from zero?

15. If the signed integral of f − g is 0, must the distance d₁ be 0?
No. Positive and negative signed differences can cancel. The metric integrates the norm or absolute value of the difference, which prevents that cancellation.
16. If the average gap is very small, must the largest gap also be very small?
No. A continuous narrow spike can have a small area but a large peak. The inequality d₁ ≤ d∞ gives a bound in the other direction: a small maximum guarantees a small average.

Approximation at any requested accuracy

What does dense mean?

Source: §2, dense subsets, ℚ in ℝ, rational approximations of π, and the motivation for approximating functions.

A subset is dense when its members can get arbitrarily close to every object in the larger space, using the chosen metric.

“Dense” is about where approximations can reach. It does not mean the subset contains every target. Imagine choosing a target and a positive tolerance. A dense subset can supply an element inside that tolerance, no matter how small the requested tolerance is.

The formal definition, one phrase at a time

Let (X, d) be a metric space and let A ⊆ X, meaning every member of A is also in X. The subset A is dense in X when:

∀x∈X,∀ε>0,∃a∈A:d(x,a)<ε
Symbol or phraseMeaning
∀ x ∈ XChoose any target object x in the larger space.
∀ ε > 0Choose any positive error tolerance, written epsilon.
∃ a ∈ AThere must be at least one suitable approximating object in the subset.
d(x, a) < εThe approximation is strictly inside the requested distance.

The choice of a may depend on both the target and the tolerance. You do not need one fixed element that works for all targets and every tolerance. The inequality is strict: an error equal to ε does not meet this definition.

Rational numbers: a familiar dense subset

ℚ={mn:m∈ℤ,n∈ℕ,n≥1}

The symbol ℚ denotes rational numbers. An integer m may be negative, zero, or positive; the denominator n is a positive integer. Examples are 1/2, −7/3, and 314/100 = 3.14. A finite decimal is rational because it can be written over a power of 10.

The lecturer’s example is π. It is not rational, but rational numbers can approximate it as closely as desired. On the real line the metric is d(x, a) = |x − a|.

Worked Example · Is 3.14 close enough?

Target: π ≈ 3.141592653589793
Approximation: a = 3.14 = 314/100
Error: |π − 3.14| ≈ 0.001592653589793

If ε = 0.01, the error is smaller than the tolerance, so this approximation qualifies. If ε = 0.001, it does not. Improve the rational approximation rather than changing the definition:

a = 3.1416 = 31416/10000
|π − 3.1416| ≈ 0.000007346410207
0.000007346410207 < 0.00001

The second approximation meets ε = 0.00001. Neither rational decimal becomes equal to π. Closeness and equality are different ideas.

Why rational approximations work for every real target

This added argument explains the source’s statement that ℚ is dense in ℝ. Given a real target x and ε > 0, choose a sufficiently large integer N so that 10−N < ε. The decimal grid then has spacing less than the tolerance.

q=m10N,m=⌊10Nx⌋;0≤x−q<10−N<ε

The floor brackets ⌊u⌋ mean the largest integer no greater than u. They choose the grid point immediately at or below x, so the gap is less than one grid spacing. The number q is rational because it is an integer divided by 10N. This works for negative targets too.

For example, x = π, ε = 0.001, and N = 4 give q = 31415/10000 = 3.1415. Its error is approximately 0.00009265, smaller than 0.0001 and therefore smaller than 0.001. The earlier 3.1416 was rounded to the nearest grid point; this proof deliberately uses the lower grid point to make the inequality easy to show.

Source clarification · Finite decimals and exact descriptions

A finite stored decimal is a rational approximation. But an irrational number such as π or √2 can still have an exact symbolic description, and algorithms can compute increasingly accurate approximations. “Cannot store infinitely many decimal digits” is not the same as “cannot describe or compute the number.” Mathematical density also does not remove a physical computer’s memory and time limits.

A subset that is not dense

The integers ℤ are not dense in ℝ with ordinary distance. Choose the target x = 0.5 and ε = 0.4. The nearest integers are 0 and 1, both at distance 0.5. No integer is strictly within 0.4 of the target. One such target-and-tolerance counterexample is enough to refute density.

From approximating numbers to approximating functions

For number approximation, X = ℝ and A = ℚ. In the lecturer’s next goal, X is replaced by a space of continuous functions, and the candidate subset consists of functions produced by neural networks. A target is then an entire function f, and an approximation is another function g.

The source denotes the family of neural-network functions by N. Saying “N is dense in C(X)” means: for every target f in C(X) and every ε > 0, there is a function g in N with d(f, g) < ε, for the specified metric and the assumptions of the relevant approximation result.

The distance must be specified. With uniform distance, d∞(f, g) < ε means every output gap is below ε. With the normalized average distance, d₁(f, g) < ε controls the average gap and may allow a narrow large error. A claim of density always belongs to a particular ambient space and metric.

Forward pointer from the source

The lecturer ends Section 2 by introducing neural networks as candidates for approximating continuous functions on a cube. The approximation theorems and their assumptions belong to Section 3 and are outside this guide. Here, the task is to understand what “dense in a function space” would mean.

Source overstatement · Approximation does not guarantee prediction

The source suggests that approximating functions would let us predict the future. This does not follow from density. Density is an existence statement about approximations to targets in a specified function class. It does not supply the target function, the needed observations, a way to find parameters, or reliable predictions on unseen inputs.

Quick Summary · The purpose of this digression

A metric makes “close” precise. Function distances tell us whether an approximation is close in the worst case or on average. Density says a chosen family can reach any target in the space to any positive requested tolerance. Always name the objects, domain, metric, and assumptions.

Added practice · Pay attention to “every” and the strict inequality.

17. If ℚ is dense in ℝ, must π itself be rational?
No. Density says rational numbers can approximate π within every positive tolerance. It does not say the target must belong to the approximating subset.
18. The required ε is 0.01 and an approximation has error exactly 0.01. Does it qualify?

19. Does a = 3.1416 approximate π within ε = 0.00001?
Yes. Its absolute error is approximately 0.00000734641, which is smaller than 0.00001. Also, 3.1416 = 31416/10000 is rational.
20. Give a target and a tolerance showing that the integers are not dense in ℝ.
Choose x = 0.5 and ε = 0.4. Every integer is at least 0.5 away, so no integer a satisfies |0.5 − a| < 0.4. Another valid choice uses the same target and any positive ε ≤ 0.5.

Absolute value
The nonnegative size of a real number: |−3| = 3.
Approximation
An object chosen to be close to a target under a specified metric.
C[−1, 1]
The continuous real-valued functions defined on the closed interval [−1, 1].
C(X)
The continuous functions on X, with the output type understood from context.
Compact domain
A mathematical condition met by a closed, bounded interval or box in Euclidean space. Continuous gaps on a nonempty compact domain attain finite maxima.
Continuous function
A function without a jump at a point: outputs approach the point’s output as inputs approach that point.
Dense subset
A subset with an element within every positive tolerance of every target in the larger metric space.
Domain
The set of allowed inputs of a function.
Epsilon, ε
A positive tolerance. In the density definition, the approximation error must be strictly smaller.
Euclidean distance, d₂
The square root of the sum of squared coordinate differences.
Function space
A collection whose elements are whole functions.
Integral
An accumulation across a region; for a nonnegative curve gap it measures area on an interval.
Maximum
A largest value that is actually attained in the chosen domain.
Metric
A finite nonnegative distance rule that separates distinct objects, is symmetric, and satisfies the triangle inequality.
Metric space
A set of objects X equipped with a chosen metric d, written (X, d).
Norm
A measure of a vector’s length. The examples here use Euclidean length.
Normalized average gap, d₁(f, g)
The integral of the output-difference size, divided by the input domain’s size, with the stated function and domain assumptions.
p-distance, dₚ
For finite p ≥ 1, add absolute coordinate differences raised to p, then take a p-th root.
Rational number, ℚ
A ratio of two integers with a nonzero denominator, which can be chosen positive.
Subset, A ⊆ X
A collection A whose elements all belong to X.
Supremum
The least upper bound; unlike a maximum, it need not be attained. Mentioned only to clarify domain assumptions.
Symmetry
The property d(x, y) = d(y, x).
Taxicab distance, d₁(A, B)
The sum of absolute coordinate changes; an ideal axis-aligned grid-route distance.
Triangle inequality
d(x, y) ≤ d(x, z) + d(z, y) for every possible third object z.
Uniform distance, d∞
The largest pointwise output gap on the chosen domain; a worst-case distance.
Vector
An ordered list of coordinates or output components.

Editorial clarifications and added support

Detours may have equal length.

The source formula uses ≤. The guide clarifies that “increases” should be read as “does not decrease,” and demonstrates equality with a point on a straight segment.

“Nice subset” needs assumptions for function distances.

For maximum gap, this guide uses nonempty compact domains with continuous functions. For normalized integral gap, its general examples use boxes of positive side lengths. It explains finite positive volume and why an arbitrary domain with isolated zero-volume pieces can defeat the separation condition.

“Area” means the appropriate domain size.

On [−1, 1], divide by length 2. In a planar region use area; in higher dimensions use volume. This preserves the source’s normalization while clarifying its terminology.

Exact descriptions differ from finite decimal storage.

π and √2 have symbolic descriptions and algorithms for numerical approximation. A finite decimal still stores a rational approximation. The guide avoids treating these different kinds of representation as the same issue.

Function approximation is not a guarantee of predicting the future.

Density expresses the existence of arbitrarily close approximants relative to a chosen metric. It does not guarantee data, a correct world model, successful learning, or reliable future predictions. Later approximation theorems also require their own assumptions.
