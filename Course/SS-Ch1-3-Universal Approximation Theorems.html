Before you begin

What this guide covers

Source: §3 — Universal Approximation Theorems and §3.1 — Implementation. Added examples and labs are teaching supplements.

A neural network is a function with adjustable numbers inside it. Universal approximation theorems explain how a large enough family of networks can come close to a target function. This guide builds from that idea to the lecturer’s example of approximating cos(x).

Your learning goals

  • Read the theorem without confusing existence with training.
  • Follow the proof’s main logic, including its technical tools.
  • Count all 102 parameters in the lecturer’s architecture.
  • Distinguish integrated loss, mean squared error, and root mean squared error.

Suggested study route

Read one lesson, work its example, use the lab, and try the questions. The proof takes extra time; use its plain-language explanation before reading the formal steps.

Allow roughly 2–3 study sessions. You can revisit any lesson from the contents menu.

Parameters → network functions → density → proof → error norms → architecture → loss → sampled data
Prerequisite Review

A function assigns an output to each input. A vector is an ordered list of numbers; a matrix arranges numbers in rows and columns. The dot product yᵀx means y₁x₁ + ··· + ydxd. A continuous function has no jumps. An integral adds contributions across a region; here it measures accumulated error.

Prerequisite Review

A metric measures distance. The uniform distance d∞(f,g) is the largest absolute output error on the whole domain. A family is dense if it contains an approximation within every positive tolerance ε of every target in the stated space. These are brief reviews of §2, not a second metric-spaces lesson.

§3 · The starting point

Learning is function approximation

Source: §3 — opening paragraphs and parameter-to-function diagram. Added examples and labs are teaching supplements.

Think of an architecture as a recipe with empty slots for numbers. Filling the slots chooses a particular network function. Learning searches for a useful choice of those numbers.

Weights control how signals combine. Biases shift the input to each activation. The lecturer groups every weight and bias into a single object P:

P=(W1,…,WL,b1,…,bL)∈RKP↦NNP

Wi is the weight matrix of layer i; bi is its bias vector; L counts the layers with parameters; K counts all scalar entries. ℝK is the set of all ordered K-tuples of real numbers. NNP means the network function obtained with parameters P, after the architecture and activations have been fixed.

Worked Example · One neuron

Use g(x) = ReLU(a₁x + a₂), with P = (2, −0.5). ReLU keeps positive values and replaces negative values with zero.

  1. At x = 0

    z = 2 × 0 − 0.5 = −0.5; g(0) = max(0, −0.5) = 0.

  2. At x = 0.5

    z = 2 × 0.5 − 0.5 = 0.5; g(0.5) = 0.5.

  3. At x = 1

    z = 2 × 1 − 0.5 = 1.5; g(1) = 1.5.

The same two parameters determine outputs at every input, not just these three. In the graph, the bend is where 2x − 0.5 = 0, namely x = 0.25.

Source Clarification · A function need not identify its parameters

The source says each point P corresponds uniquely to a network instance. The map is well defined, but it need not be one-to-one as a map to functions. For example, P = (0, −1) and P = (0, −2) both give the identically zero ReLU function. Swapping equivalent hidden units is another source of repeated representations.

Why this viewpoint matters

Approximating a curve with a network is similar in purpose to approximating a function with a Taylor polynomial or a Fourier sum: choose coefficients to make a simpler expression behave like the target. Neural networks also learn the shapes and positions of their building blocks. In applications, inputs may be measurements rather than a single x, and the target may describe a physical response or a prediction rule.

Quick Summary

Architecture fixes the computation pattern. P fills its numerical slots. NNP is the resulting function. Training changes P to reduce a chosen error.

§3 · The theorem

What “universal” actually promises

Source: §3 — Cybenko theorem and density explanation. Added examples and labs are teaching supplements.

Imagine a box containing networks of every finite hidden-layer width. Universality says that this box contains a sufficiently accurate network for each continuous target on the stated domain, if the activation meets the theorem’s conditions.

Read one building block first

A hidden unit computes σ(yiTx + bi). The output layer multiplies it by αi and adds all the units. Here x is a d-dimensional input, yi is its d-dimensional weight vector, bi is its scalar bias, σ is the fixed activation, and αi is a scalar output weight. N counts hidden units. The source’s family is:

N2=⋃N=1∞{∑i=1Nαiσ(yiTx+bi):yi∈Rd,αi,bi∈R}

The union symbol ⋃ means “allow every positive finite N.” The subscript 2 follows the lecturer’s convention: one hidden transformation and one linear output transformation. It does not mean two hidden layers. The coefficients and biases can vary freely.

Worked Example · Evaluate a two-unit sum

For the logistic sigmoid σ(t) = 1/(1 + e−t), let g(x) = 2σ(x) − σ(−x), where x is a single number. At x = 0, each sigmoid is 1/(1 + 1) = 0.5. Therefore g(0) = 2 × 0.5 − 1 × 0.5 = 0.5. Negative output weights are allowed; the sum is not restricted to sigmoid’s output range.

Cybenko’s theorem · carefully stated

Let Id = [0,1]d, the unit cube. Let C(Id,ℝ) contain all continuous real-valued functions on it. If σ is continuous and discriminatory, then 𝒩₂ is dense in that space under the uniform distance:

d∞(f,g)=maxx∈Id|f(x)−g(x)|<ε
For every continuous fand every ε > 0there exists a finite N and parametersthat work for every input x in Id

For example, with f(x) = x² on [0,1] and ε = 0.01, some finite network has absolute error below 0.01 everywhere in that interval. The theorem does not give a numerical width or a set of weights for that request. A new target or a smaller tolerance may require a larger width and different parameters.

Source Clarification · Continuity is required here

The lecture’s theorem says “discriminatory” but uses a subspace of continuous functions in its proof. The continuity assumption is explicit in Cybenko (1989), Theorem 1, journal p. 306. A continuous sigmoidal activation, such as the logistic sigmoid, satisfies the needed discriminatory condition.

From a unit cube to the cosine interval

The lecturer later uses [−10,10]. Put u = (x + 10)/20, so x = 20u − 10 and u lies in [0,1]. The transformed target h(u) = cos(20u − 10) is continuous. Approximating h and substituting u gives an approximation on the original interval. The affine substitution is absorbed into hidden weights and biases; universality is not limited to inputs numerically between 0 and 1.

x = −10 → u = 0; x = 0 → u = 0.5; x = 10 → u = 1.

Common Mistake · Existence is not an optimization guarantee

The theorem allows enough hidden units. It does not promise that a specific width, a random initialization, a finite dataset, or gradient descent will achieve any requested accuracy. It gives no general guarantee about speed, generalization, extrapolation, or exact equality to f.

5. What does the union over N add to the family 𝒩₂?
It permits all positive finite hidden widths. A theorem about this union is not a guarantee for one preselected width.

No. There may be larger errors between the points. A certified global bound requires additional analysis, such as a valid continuity or derivative bound with sufficiently fine spacing.

§3 · Definition and proof

Why the approximation family is dense

Source: §3 — discriminatory definition and displayed proof. Added examples and labs are teaching supplements.

The proof argues by contradiction. If the networks missed some continuous functions even after taking limits, a mathematical “detector” could distinguish that missing direction. A discriminatory activation makes such a detector impossible.

What is a discriminatory activation?

Here “discriminatory” is a technical word about detecting signed measures. It does not refer to demographic bias or to a classification label. A signed measure assigns positive or negative weights to sets and lets us integrate functions against them. M(Id) denotes finite signed regular Borel measures on the cube. “Finite” means finite total variation; “Borel” refers to the usual measurable sets generated by open sets. These are the measures represented by the theorem used below.

The definition says:

∫Idσ(yTx+θ)dμ(x)=0∀y∈Rd,θ∈R⇒μ=0

y is an arbitrary weight vector, θ an arbitrary bias, μ the signed measure, and dμ indicates integration against that measure. μ = 0 means every measurable set receives zero measure. It means much more than having total mass zero. The lecturer uses In in this definition; d and n play the same role as input dimension. We use d consistently.

Worked Example · Cancellation can hide information

For μ = δ₀ − δ₁, a constant probe gives ∫1 dμ = 1 − 1 = 0 even though the measure is nonzero. A sigmoid probe with y = 2 and θ = 0 gives σ(0) − σ(2) = 0.5 − 0.880797 ≈ −0.380797. This probe detects it. One zero response was not enough to conclude μ = 0.

The proof, one logical step at a time

1

The network family is a linear subspace

Write S = 𝒩₂ ⊆ C(Id,ℝ). Adding two finite sums produces another finite sum by joining their hidden units. Multiplying a sum by any real number just scales its output weights αi. The zero function is allowed by choosing zero output weights. Continuity of σ makes every such function continuous.

A fixed width need not be closed under addition at that same width; allowing the union over widths is essential here.

2

Assume the family is not dense

Let A = closure(S), meaning all uniform limits of sequences from S. It is a closed linear subspace of C(Id,ℝ). If density fails, A is proper: some continuous f₀ lies outside it. The ambient space, with the uniform norm, is a Banach space, meaning Cauchy sequences converge within it; A inherits completeness.

3

Use Hahn–Banach to obtain a nonzero detector ℓ

The separation consequence of Hahn–Banach gives a bounded linear functional ℓ on C(Id,ℝ) with ℓ(a) = 0 for every a ∈ A but ℓ(f₀) ≠ 0 for some f₀ outside A. A linear functional turns a function into a real number while respecting addition and scaling. Bounded means continuous in the uniform norm.

For a finite-dimensional analogy, if A is the horizontal axis in ℝ², the detector ℓ(u,v) = v vanishes on A and detects the vertical direction. The actual proof works in a space of functions.

4

Represent the detector using a signed measure

The Riesz–Markov–Kakutani representation theorem gives a finite signed regular Borel measure μ on Id such that, for every continuous h,

ℓ(h) = ∫Id h(x) dμ(x)

h is any continuous test function, ℓ(h) is its scalar detector response, and μ supplies the signed weights. In the finite example above, this rule is simply ℓ(h) = h(0) − h(1).

5

Every single activated affine function is invisible to ℓ

Each h(x) = σ(yᵀx + θ) is a width-one member of S, hence belongs to A. Therefore ℓ(h) = ∫σ(yᵀx + θ)dμ(x) = 0 for every y and θ.

6

Discriminatory status forces a contradiction

The definition implies μ = 0. Integrating any continuous function against the zero measure gives zero, so ℓ(f₀) = ∫f₀dμ = 0. This contradicts Step 3. The assumption that A was proper must fail. Thus closure(S) = C(Id,ℝ): S is dense.

Source Clarification · How the nonzero functional is obtained

Merely extending the zero functional from A could give the zero functional everywhere. The proof needs the nonzero separating functional guaranteed for a proper closed subspace, as stated in Step 3. This supplies the missing justification in the lecture’s extension wording. See Cybenko, proof of Theorem 1, p. 306.

What about proving that σ is discriminatory?

The lecturer leaves this next stage unproved. This guide keeps that boundary. For a continuous sigmoidal σ, the required fact is available, so the logistic sigmoid is a valid example. The test in this proof concerns all finite signed measures on the cube; the lecture’s phrase “with respect to the Lebesgue measure” does not state the full requirement. Checking Lebesgue integration alone is insufficient for this argument. Cybenko’s Lemma 1, pp. 307–308, supplies the sigmoidal case.

Beginner Tip

You do not need to prove Hahn–Banach or the representation theorem to follow this argument. Know their roles: the first produces a detector; the second expresses that detector as integration. Discriminatory status then eliminates it. The measure-theoretic lemma is outside the proof supplied in the selected lecture.

Check Your Understanding · Discriminatory functions and proof

Added practice for private study, not an official lecturer examination. Attempt each question before opening its answer.

9. In the definition, is one pair (y, θ) enough to conclude μ = 0?
No. The premise must hold for all y and θ. The y = 0 sigmoid probe is blind to δ₀ − δ₁, but other probes detect it.
10. Why does joining two hidden-unit sums show closure under addition?
If the first uses N units and the second uses M, their sum is a finite sum with N + M units. That sum remains in the union 𝒩₂.
11. What would go wrong if the functional ℓ were the zero functional from the start?
There would be no f₀ with ℓ(f₀) ≠ 0, so the final contradiction would disappear. Nonzero separation is essential.
12. Locate the exact contradiction at the end of the proof.
Step 3 gives ℓ(f₀) ≠ 0. The representation and discriminatory property force μ = 0, hence ℓ(f₀) = ∫f₀dμ = 0. Both cannot hold.

§3 · Hornik and error norms

Close everywhere, or close on average?

Source: §3 — Hornik theorem and Lᵖ distance. Added examples and labs are teaching supplements.

The meaning of “good approximation” depends on the error measure. Uniform error protects every input in the domain. An integral-based error measures how much error accumulates over the domain.

The lecturer’s normalized Lᵖ distance

dp(f,g)=(1vol(Id)∫Id|f(x)−g(x)|pdx)1p1≤p<∞

f is the target, g is the approximation, |f(x) − g(x)| is absolute error at input x, p is a finite exponent at least 1, and dx denotes ordinary volume integration. vol(Id) is the cube’s d-dimensional volume; the lecture calls it “area.” On the unit cube it equals 1, so normalization changes nothing numerically. On [−10,10] the corresponding length is 20.

MetricHow to read itTypical purpose
d₁Average absolute errorA summary in output units
d₂Square root of average squared errorLarger errors receive more weight
d∞Largest absolute error on the domainControl of the worst location

Worked Example · A constant error of 0.2

If |f(x) − g(x)| = 0.2 everywhere on [−10,10], then the squared-error integral is 20 × 0.2² = 0.8. Divide by 20 to obtain average squared error 0.04. Taking a square root gives d₂ = 0.2. The uniform distance is also 0.2. These quantities agree here because the error is constant; they need not agree for varying errors.

What the Hornik result contributes

Under the source’s assumptions that σ is continuous, bounded, and nonconstant, the variable-width one-hidden-layer family can approximate continuous targets uniformly on compact sets. Thus it also approximates them in each finite-p norm on the unit cube.

Source Clarification · Finite p and the endpoint ∞

The paper linked by the lecturer was published in 1991 (received in 1990). Its Lᵖ theorem covers 1 ≤ p < ∞; its separate compact-set theorem gives uniform approximation for continuous targets. Thus the lecture’s continuous-target conclusion at p = ∞ is supported under its assumptions, but it should not be read as density in all of L∞, including discontinuous functions. See Hornik (1991), Theorems 1–2, journal p. 252.

The finite-p formula does not accept p = ∞ as an ordinary substitution. Define that endpoint separately using the essential supremum. For continuous functions on the full compact cube with ordinary volume measure, it agrees with the maximum used in d∞. This is why the lecture can discuss both in the same continuous-function setting.

Why uniform control also gives average control

If the absolute error is at most δ everywhere, its p-th power is at most δᵖ. Integrating and dividing by volume leaves at most δᵖ. Taking the p-th root gives dₚ(f,g) ≤ δ. A narrow, tall error shows why a small finite-p distance does not give the same worst-case bound.

The logistic sigmoid is continuous, bounded, and nonconstant. A constant activation cannot express varying outputs. 13. If g differs from f by 0.3 everywhere on a length-20 interval, find integrated squared error, MSE, and d₂.

No. The endpoint is defined separately by essential supremum. In this continuous compact-cube setting it equals the maximum absolute error.

§3.1 · A target for optimization

Measure cosine approximation error

Source: §3.1 — continuous and point-wise loss definitions. Added examples and labs are teaching supplements.

A graph helps us see a fit, but optimization needs one number to compare parameter choices. The lecturer uses integrated squared error over the whole input interval.

loss(P)=∫−1010(cos(x)−NNP(x))2dx=20d2(cos,NNP)2

P is the complete parameter vector. NNP(x) is the predicted output at x; cos(x) is the target. Squaring removes the sign of the error and penalizes larger deviations more strongly. Integrating adds that squared error over [−10,10]. The loss is a nonnegative real number, so it is a function loss: ℝ¹⁰² → ℝ (more specifically, into [0,∞)).

From the normalized metric definition:

d₂(cos, NNP) = √[(1/20) ∫−1010 |cos(x) − NNP(x)|² dx]

Worked Example · Translate a stopping target

If loss(P) = 0.8, then MSE = 0.8/20 = 0.04 and d₂ = √0.04 = 0.2. If the desired distance is d₂ < 0.1, then squaring and multiplying by 20 gives loss(P) < 20 × 0.1² = 0.2.

Conversely, a request for loss(P) < ε gives d₂ < √(ε/20). The ε used for a distance tolerance and the ε used for a squared integrated loss need not be the same numerical target. Always name the quantity you want below a threshold.

Worked Example · A baseline that predicts zero

Choose NNP(x) = 0, which the source architecture can produce by setting W₃ and b₃ to zero. Then the point-wise squared loss is cos²(x). Using cos²(x) = (1 + cos(2x))/2:

∫−1010 cos²(x) dx = [x/2 + sin(2x)/4]−1010
= 10 + sin(20)/2 ≈ 10.456473.
MSE ≈ 10.456473/20 = 0.522824.
d₂ ≈ √0.522824 = 0.723065.

The sine and cosine arguments here are in radians. A lower empirical MSE than this baseline is useful evidence at the sampled inputs; it does not alone certify improvement on the full interval.

Point-wise loss: one input at a time

l(P,x) = |cos(x) − NNP(x)|²

Lowercase l depends on both the chosen parameters P and one input x. For example, at x = 0, cos(0) = 1. If the network predicts 0.7, the residual is 1 − 0.7 = 0.3 and l(P,0) = 0.3² = 0.09. An output of 1.3 gives residual −0.3 and the same squared loss.

Source Clarification · Integration is a practical issue, not always impossible

The lecture motivates sampling because the network may be difficult to integrate analytically. That is a practical reason, not a universal impossibility claim. The zero baseline above is exactly integrable, and some other networks admit analytic or numerical integration. Empirical loss remains useful when learning from available data.

§3.1 · From integrals to data

Empirical loss and what it estimates

Source: §3.1 — sampled loss, convergence statement, and closing motivation. Added examples and labs are teaching supplements.

Instead of integrating over every input, evaluate the network at a finite dataset D = {x₁, …, xN}. Compute the squared error at each input and average the results. This is empirical loss: an error measured from data.

lossD(P)=1N∑i=1N|cos(xi)−NNP(xi)|2

D is the collection of sampled input values, N is its size, i labels an example, and P is the same fixed parameter vector throughout the average. The subscript D records which dataset was used. Here N counts data points, whereas N in the theorem’s network sum counts hidden units: these are different uses of a letter.

Worked Example · Three measured errors

Suppose target-minus-prediction residuals at three data points are 0.2, −0.4, and 0.1. The individual losses are 0.04, 0.16, and 0.01.

lossD(P) = (0.04 + 0.16 + 0.01)/3 = 0.21/3 = 0.07.
Sample RMSE = √0.07 ≈ 0.264575.
Uniform-input integral estimate = 20 × 0.07 = 1.4.

The last conversion is justified as an estimate of the original integral only when the sampling represents the uniform distribution on [−10,10]. Three arbitrary points do not make it accurate automatically.

Source Correction · A missing factor of 20

One displayed line says loss(P) ≈ lossD(P). With loss(P) defined as an unnormalized integral and lossD as an average, the consistent relation for uniform sampling is loss(P) ≈ 20 lossD(P), or equivalently loss(P)/20 ≈ lossD(P). The source’s following limiting formula already has this normalization. Minimizers are unchanged by a positive constant factor, but numerical tolerances and gradient magnitudes are scaled.

When does the empirical average converge?

The source says it converges “by continuity.” Continuity alone is not enough: the sample locations also matter. There are two useful interpretations for a fixed P and a continuous network:

  • Evenly spread grids. Midpoint Riemann averages on partitions with mesh tending to zero converge to loss(P)/20. Equal-width cells have equal weight. Suitable increasingly fine uniform grids also work.
  • Independent uniform random samples. The law of large numbers gives convergence to the uniform-input expected squared error, loss(P)/20. On this compact interval the continuous squared error is bounded, so it is integrable.

If inputs follow a different distribution q, the average instead estimates expected error under q. If all samples stay concentrated near x = 0, increasing their number does not recover a uniform average over [−10,10]. If P is selected using the same data, a convergence claim for each fixed P does not by itself guarantee the performance of the data-selected network; validation on other data is useful.

Review and reference

Bring the ideas together

Source: §3 and §3.1 — selected content only. Added examples and labs are teaching supplements.

Quick Summary

  • The search space: a fixed architecture maps parameter vectors P to functions NNP.
  • The existence claim: with the stated activation conditions and enough hidden units, the family is dense in the appropriate function space.
  • The proof: assume a gap → separate it with a nonzero functional → represent that functional by a signed measure → use discriminatory status to force a contradiction.
  • The example: 1 → 13 → 5 → 1 gives 83 weights and 19 biases, hence 102 parameters.
  • The error accounting: integrated loss = 20 × uniform-input MSE = 20d₂² on [−10,10].
  • The data limit: a representative empirical average estimates a mean error. Neither a small sample loss nor the existence theorem guarantees successful learning.

Glossary

Architecture
The fixed computation pattern: layer sizes, connections, and activation choices.
Parameter vector P
The ordered collection of every scalar weight and bias.
NN_P
The function computed by the chosen architecture with parameters P.
Activation σ
A function applied to a neuron’s affine input; often applied coordinate by coordinate.
Affine function
A weighted sum plus a bias, such as yᵀx + b.
Hidden width
The number of neurons in a hidden layer.
Unit cube I_d
[0,1]ᵈ: all d-dimensional inputs whose coordinates lie between 0 and 1.
C(I_d,ℝ)
The space of continuous real-valued functions on the unit cube.
Dense family
A family containing approximations within every positive tolerance in the stated metric.
Closure
The original set together with all of its limits under the chosen notion of convergence.
Uniform distance d∞
The maximum absolute error over the whole compact domain for continuous functions.
Normalized Lᵖ distance
The p-th root of average absolute error to the p-th power, for finite p ≥ 1.
Discriminatory activation
An activation whose full family of affine probes cannot all annihilate a nonzero finite signed regular Borel measure.
Signed measure μ
A rule assigning positive or negative weights to measurable sets.
Linear functional ℓ
A linear rule taking a whole function as input and returning a real number.
Bounded functional
A continuous linear functional; its response is bounded by a constant times the input norm.
Banach space
A normed vector space in which every Cauchy sequence converges within that space.
Empirical loss
An average error evaluated on a finite dataset.
Population MSE
The expected squared error under a specified input distribution.
RMSE
The square root of mean squared error; for uniform inputs here it equals normalized d₂.
Existence theorem
A result ensuring that an object exists without necessarily giving a practical way to find it.
Compact domain
A closed and bounded domain in finite-dimensional Euclidean space; continuous functions attain maxima there.
