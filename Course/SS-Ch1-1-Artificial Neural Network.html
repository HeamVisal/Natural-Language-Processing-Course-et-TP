01

The smallest useful building block

What does a neuron do?

Source: §1 — Artificial Neural Network, signals, neurons, and weighted sums.

An artificial neural network is a function built from many small calculations. Each artificial neuron receives numbers, combines them, and passes a number forward.

The lecture begins with a visual signal moving through groups of biological neurons until a judgement is made, such as “cat” or “flower.” This motivates an artificial network with an input layer, hidden layers, and an output layer. It is a useful mathematical analogy, rather than a detailed model of the brain.

In an application, an image must first be represented by numbers, such as pixel values. In language applications, words also need a numerical representation. This section studies the function that processes those numbers; it does not yet teach image encoding or word embeddings.

Why a plain sum is not enough

Imagine a decision based on two numerical clues. If one clue is more useful, it should have a different influence. A weight is the multiplier that controls that influence. A positive weight keeps the sign of an input; a negative weight reverses it. A zero weight removes that input’s contribution.

For a receiving neuron, multiply each input by its connection weight and add the products. This is a weighted sum.

Worked Example · One neuron, two inputs

Let the input values be x₁ = 2, x₂ = 3, with weights w₁ = 0.5, w₂ = 2. A bias adds an adjustable offset after the weighted sum. Here use b = 1.

  1. Find the two contributions.

    0.5 × 2 = 1, and 2 × 3 = 6.

  2. Add them to get the weighted sum.
    s = 1 + 6 = 7
  3. Add the bias.
    z = s + b = 7 + 1 = 8

    The number z is the pre-activation: the value before applying an activation function.

  4. Apply ReLU.
    output = max(0, z) = max(0, 8) = 8

    ReLU keeps positive values and replaces nonpositive values with 0. We study it carefully in Part 03.

This equation is useful every time a dense neuron computes its next output. One neuron produces one number; a layer performs many of these calculations together.

02

Many neurons, one calculation

Vectors become layers

Source: §1, dot products, layer matrices, and the linear-layer problem.

A layer is a group of neurons that receives the same input vector. Each neuron has its own weights. Put those weight vectors into rows, and you can calculate the whole layer with one matrix multiplication.

A vector’s order matters. If X = (2, 3)T, the first entry is 2 and the second is 3. A matrix row is the recipe for one output: match each entry of the row with the corresponding input, multiply, then add.

Wi=[w1,1iw2,1i⋯wkᵢ₋₁,1iw1,2iw2,2i⋯wkᵢ₋₁,2i⋮⋮⋱⋮w1,kᵢiw2,kᵢi⋯wkᵢ₋₁,kᵢi]=[(W1i)T⋮(Wkii)T]

The source writes a connection as wk,ji, with source index first and receiving index second. That connection goes in row j, column k of the matrix. This explains why the first matrix row above contains w₁,₁, w₂,₁, and so on.

Beginner Tip · Check the dimensions

An input with n entries and an output with m entries needs an m × n matrix: m rows, n columns. The inner dimensions match in (m × n)(n × 1) = m × 1. A superscript such as Wⁱ labels the layer; it does not change this rule.

Xi=WiXi−1,Wi∈ℝki×ki−1

Here kᵢ₋₁ is the input width and kᵢ is the output width. This particular equation is the lecture’s early model, before adding biases and activations.

Worked Example · Two inputs, three outputs

[.521−1−1.5][23]=[7−1−.5]
  1. First output.
    0.5 × 2 + 2 × 3 = 1 + 6 = 7
  2. Second output.
    1 × 2 + (−1) × 3 = 2 − 3 = −1
  3. Third output.
    (−1) × 2 + 0.5 × 3 = −2 + 1.5 = −0.5

Each row reads the same input (2, 3), but uses different weights. The output vector (7, −1, −0.5) contains all three results. This is useful for implementing a whole layer efficiently.

The surprising problem: all-linear layers collapse

Passing through two linear layers gives W²(W¹X⁰). Matrix multiplication is associative, so you can multiply the matrices first. The same reasoning works for any number of layers.

XL=WLWL−1⋯W1X0=WX0

For example, choose W¹ = [[1, 2], [−1, 1]], W² = [[2, −1]], and X⁰ = (1, 3)T.

  1. Compute the hidden vector.
    X¹ = (1×1 + 2×3, −1×1 + 1×3)ᵀ = (7, 2)ᵀ
  2. Compute the final result.
    X² = 2×7 − 1×2 = 12
  3. Combine the matrices instead.
    W²W¹ = [2×1 + (−1)×(−1), 2×2 + (−1)×1] = [3, 3]
    [3, 3] × (1, 3)ᵀ = 3×1 + 3×3 = 12

Two layers produced exactly the same function as one matrix. More linear layers alone do not create a more expressive class of functions.

Extra Explanation · Biases alone do not fix this

Two affine layers still combine into one affine map:

Af2(Af1(x))=(W2W1)x+W2b1+b2

The product W²W¹ is the new matrix, and W²b¹ + b² is the new bias. What prevents this general collapse is a nonlinear activation between the affine maps.

Source notation note

In the paragraph about another neuron in layer i, the source refers once to Wmi−1. Its preceding definitions and the next matrix equation require Wmi: weights belong to the layer receiving the signal. This guide uses that consistent index.

03

The ingredient that makes depth useful

Gates & activation functions

Source: §1, threshold gates, ReLU, SiLU, sigmoid, tanh, and softplus.

An activation function changes a neuron’s pre-activation before the result travels to the next layer. A nonlinear activation lets a network build functions that cannot always collapse into one affine map.

The lecture uses two analogies: signals crossing a synaptic gap, and water accumulating before a drop falls. Both suggest a threshold. An artificial activation is a mathematical rule inspired by this idea; it is not a full biological or physical simulation.

ReLU: keep positive values, suppress the rest

ReLU(u)=max(0,u)={uif u > 00if u ≤ 0

The argument u is any real number. max(0, u) means “choose the larger of 0 and u.” So ReLU(−3) = 0, ReLU(0) = 0, and ReLU(2.5) = 2.5. The name means rectified linear unit. The source spells it “ReLu”; this guide uses the standard capitalization “ReLU.”

A threshold moves the point where the output becomes positive. For an incoming weighted sum s and threshold θ:

ReLU(s−θ)=max(0,s−θ)

For example, s = 2 and θ = 1 give u = 2 − 1 = 1, so the output is 1. If s = 0.5 with the same threshold, u = −0.5 and the output is 0. At s = θ, the output is exactly 0.

Source inconsistency · Threshold versus additive bias

The source first uses ReLU(x − b) for a threshold, then writes the layer rule as ReLU(WX + b). These use opposite signs if the same b is intended. To make the distinction explicit, this guide writes a threshold as θ and an additive bias as b.

z=s+b,ReLU(z)>0⇔s>−b;b=−θ

Example: a threshold θ = 1 means an additive bias b = −1. A positive additive bias b = 1 instead makes the activation positive as soon as s > −1. Every neural-network calculation and PyTorch example here uses the + b convention.

“Pointwise” means one entry at a time

If a layer produces a vector, apply the activation independently to every entry. You do not add the entries or apply a different rule to the whole list.

σ([−203])=[σ(−2)σ(0)σ(3)];ReLU([−203])=[003]

The same principle holds for a general vector v = (v₁, …, vN): σ(v) = (σ(v₁), …, σ(vN)). Here N is the number of entries and σ is the chosen scalar activation. This keeps the vector’s shape unchanged.

A hard gate and a soft gate

The source calls ReLU a hard gate because it produces an exact zero when u ≤ 0. For a softer transition, it introduces SiLU, the sigmoid linear unit.

sigmoid(u)=eu1+eu=11+e−u
SiLU(u)=usigmoid(u)

Sigmoid gives a value strictly between 0 and 1 for any finite u. Multiplying u by that value controls how much of u passes through. With a threshold, use u = s − θ in both factors: SiLU(s − θ) = (s − θ) × sigmoid(s − θ).

Prerequisite Review · e and ln

The constant e is approximately 2.71828. The expression eu is an exponential. The natural logarithm ln reverses it: ln(eu) = u. In particular, e⁰ = 1 and ln(1) = 0. The formulas below use those two functions.

Worked Example · Compare the gates at u = 1 and u = −1

  1. Calculate sigmoid(1).
    e¹ ≈ 2.71828
    sigmoid(1) = 2.71828 / (1 + 2.71828) ≈ 0.73106
  2. Use it inside SiLU.
    SiLU(1) = 1 × 0.73106 ≈ 0.73106

    ReLU(1) is 1, so SiLU lets through a smaller positive value here.

  3. Try a negative input.
    e⁻¹ ≈ 0.36788
    sigmoid(−1) = 0.36788 / 1.36788 ≈ 0.26894
    SiLU(−1) = −1 × 0.26894 ≈ −0.26894

    ReLU(−1) is 0. SiLU can produce a small negative output. It approaches 0 from below as u becomes very negative.

For large positive u, sigmoid(u) approaches 1, so SiLU(u) is close to u. For very negative u, the product approaches 0. At u = 0, SiLU is exactly 0; near 0 it is generally not zero.

Common Mistake · ReLU is not an on/off output of 0 or 1

The gate is either suppressing a value or allowing a positive amount through, but that amount may be 0.1, 2, or 100. ReLU is continuous; its graph has a corner at 0. “Hard gate” here refers to its exact-zero region, not a discontinuous step function.

Two more activations in the lecture

tanh(u)=eu−e−ueu+e−u

tanh, the hyperbolic tangent, gives outputs strictly between −1 and 1 for finite inputs. It is negative for negative u and positive for positive u. At u = 1, the numerator is approximately 2.71828 − 0.36788 = 2.35040. The denominator is 3.08616. The result is about 0.76159. The source’s PyTorch network uses this activation.

softplus(u)=ln(1+eu)

Softplus is a smooth, always-positive alternative to ReLU. At u = 1, softplus(1) = ln(1 + 2.71828) = ln(3.71828) ≈ 1.31326. At u = 0, it is ln(2) ≈ 0.69315, so it does not share ReLU’s exact-zero region.

04

Intuition becomes the formal definition

Put a network together

Source: §1, affine maps, function composition, the network definition, and architecture.

Linear and affine are related, but different

A linear map has the form L(x) = Wx. It sends the zero vector to zero. An affine map adds a translation: Af(x) = Wx + b. In one dimension, it is the familiar line y = ax + b. With a nonzero intercept, that line is affine rather than linear in the strict mathematical sense.

L(x)=Wx;Af(x)=Wx+b

Here x has n entries, W has m rows and n columns, and b has m entries. The output has m entries. For example, x = 2, W = 3, and b = 1 give Af(2) = 3×2 + 1 = 7, while L(2) = 6 and Af(0) = 1.

The lecture denotes the collection of linear maps by L(ℝⁿ, ℝᵐ) and m × n matrices by Mm×n. With the standard coordinate bases, each such matrix represents exactly one such linear map.

Mm×n↔L(ℝn,ℝm)

Read the composition from right to left

The composition symbol ∘ means “do the function on the right first.” For example, let Af₁(x) = 2x + 1, σ = ReLU, and Af₂(h) = 3h − 2. At x = 1:

Af₁(1) = 2×1 + 1 = 3
σ(3) = ReLU(3) = 3
Af₂(3) = 3×3 − 2 = 7

So (Af₂ ∘ σ ∘ Af₁)(1) = 7. Reversing the order generally changes the result.

Formal Definition · From the lecturer

A neural network is a function built by composing affine maps with nonlinear functions. In the source’s formal convention, a network NN : ℝⁿ → ℝᵐ has L affine layers, with activations between them and a final affine output layer.

NN(x)=AfL∘σL−1∘AfL−1∘⋯∘Af2∘σ1∘Af1(x)

The displayed general pattern is for L ≥ 3. For two affine layers, the whole expression is simply:

NN(x)=Af2(σ1(Af1(x)))

For L = 1 there is just Af₁(x). Each map is Afᵢ(v) = Wⁱv + bⁱ, from ℝkᵢ₋₁ to ℝkᵢ. Set k₀ = n and kL = m. Each σᵢ acts pointwise on the corresponding hidden vector. The letter v is a temporary name for the input of that particular layer.

The same definition can be followed as a sequence of layer outputs:

X0=x;Xi=σᵢ(WiXi−1+bi) for 1 ≤ i < L; XL=WLXL−1+bL

In this rule X⁰ is the input x, Xⁱ is a hidden-layer output, and Xᴸ = NN(x) is the final output. Wⁱ has shape kᵢ × kᵢ₋₁; bⁱ and Xⁱ have kᵢ entries. The hidden activations σᵢ keep those kᵢ entries.

Source convention note · The output activation

The source first shows a ReLU recurrence for every layer, then gives a formal definition with an affine final layer. These are different output conventions. This guide follows the formal definition and the later PyTorch example: activate hidden layers, then finish with an affine map. A final activation can be added for a particular task, but it is not automatic.

Architecture describes the arrangement

The architecture specifies the layers, their widths, connections, and activation functions. The parameters are the numerical weights and biases inside that arrangement. In the example, the architecture is “2 → 2 → 1, hidden ReLU, affine output.” Changing a weight changes the function without changing that architecture.

The source colors connections by signed weight. A positive weight and a negative weight have different effects; the magnitude tells you the multiplier’s size. Each receiving neuron also has its own bias, so one layer has a bias vector, not just one shared scalar.

Computing outputs with current parameters is a forward pass. Training is the separate process of adjusting parameters from data. This selected section builds and evaluates functions. Gradient descent, losses, and the training procedure belong to later source sections.

Quick Summary · Section 1

A neuron combines inputs using weights and a bias. A layer packs these calculations into a matrix operation. Nonlinear activations make compositions more expressive than a stack of affine maps. Architecture describes the arrangement; parameters determine the particular function.

Meet PyTorch tensors

Source: §1.1 — Coding Neural Networks with PyTorch, imports, tensors, arithmetic, plotting, and slicing.

PyTorch represents numbers in tensors and combines layers using Python objects. A tensor is a numerical array: it may be a single number, a vector, a matrix, or an array with more dimensions.

Before you run the Python

The code blocks below are real Python examples. Run them in order in a notebook or Python session with torch and matplotlib installed. The browser labs use equivalent JavaScript calculations; they do not run Python or require PyTorch.

If those packages are missing in your own Python environment, the basic installation command is python -m pip install torch matplotlib. Package installation needs internet access. This HTML itself has no external fonts, scripts, or other dependencies.

Start with two small tensors

torch.tensor([...]) creates a tensor from the numbers in a Python list. The square brackets describe an ordered list. These two tensors both have shape (2,): one dimension, containing two entries. The comma is Python’s way of writing a one-item shape tuple.

Common Mistake · Multiplication syntax

In Python, ** means a power, * means elementwise multiplication for tensors, and @ means matrix multiplication when the shapes permit it. Python’s ^ operator is not exponentiation. The expression a ** 2 - 3 * a means a² − 3a at every entry.

Source clarification · Tensor, not Python list

The source informally calls these slices “lists of numbers.” They are PyTorch tensors. Neither a shape (3,) tensor nor a shape (2,) tensor is automatically a two-dimensional row or column matrix. Also, the mathematical entry x₂₃ corresponds to Python’s x[1, 2]: mathematical indices in the displayed matrix start at 1, while Python starts at 0.

Affine layers & batches

Source: §1.1, nn.Linear, stored parameters, batches, and objects.

nn.Linear(n, m) creates an affine layer that turns n input features into m output features. The layer stores a weight matrix and, by default, a bias vector.

PYTHON · Inspect a layerSource operation, with shape prints added

b = L.bias

print(b.shape)  # torch.Size([3])

without_bias = nn.Linear(2, 3, bias=False)

With nn.Linear(2, 3), the weight W has shape (3, 2) and b has shape (3,). Initial parameter values are sampled by PyTorch, so you should not expect the exact random numbers printed in the lecture. With bias=False, the layer has no bias parameter; its bias attribute is None and the mathematical map is Wx.

Terminology note · A “Linear” layer is usually affine

The source correctly gives L(x) = Wx + b but later calls this a linear map. With nonzero bias it is affine in the mathematical sense. PyTorch’s class name nn.Linear uses the conventional machine-learning name. A layer has no activation unless you apply one separately.

Use known numbers before random parameters

For a reproducible arithmetic example, explicitly set the weights and bias. These are added teaching values; they are not the source’s random initialization.

#         [ 3.0000, -0.5000,  0.5000]])

copy_ copies the values into the existing parameter; the underscore marks an in-place operation. The torch.no_grad() context is appropriate here because we are assigning parameters and evaluating, not constructing a training computation. The input uses decimal numbers so it has a floating-point type compatible with the layer’s default parameters.

    First output: 0.5×2 + 2×3 + 1 = 8

    Third output: −1×2 + 0.5×3 + 0 = −0.5
  2. Second input vector: (0, 1).

    Second output: 1×0 − 1×1 + 0.5 = −0.5
    Third output: −1×0 + 0.5×1 + 0 = 0.5

A batch is several inputs processed with the same layer

A batch groups multiple examples so they can use the same parameters efficiently. If a batch has k examples and each has n features, its shape is (k, n). An nn.Linear(n, m) layer produces shape (k, m): one m-entry output for each example.

The mathematics above uses column vectors, Wx + b. PyTorch commonly stores batch examples as rows. Give the batch matrix a different capital letter, B, to avoid confusing it with the bias b:

Y=BWT+b,B∈ℝk×n,W∈ℝm×n,Y∈ℝk×m

W still has m rows and n columns. Its transpose Wᵀ has n rows and m columns, so the product (k × n)(n × m) has shape k × m. Adding b means adding its m entries to each output row. The same weights and bias are reused; batching does not create a different layer per example.

Source clarification · A batch is common, not mandatory

The source emphasizes a two-dimensional input [batch_size, input_dim]. A single vector of shape (n,) is also valid and gives (m,). More generally, nn.Linear transforms the final dimension and preserves leading dimensions. The last input dimension must equal n.

Objects store both data and behavior

In object-oriented programming, an object combines stored data, called attributes, with operations, called methods. Here L is an object. L.weight and L.bias are attributes. Calling L(batch) evaluates the layer.

The parameters are PyTorch Parameter objects, a special kind of tensor. requires_grad=True means PyTorch can record operations needed to compute derivatives. A derivative describes sensitivity to change; the training method that uses it is taught later.

PYTHON · Inspect gradient-related attributesExtra explanation of source wording
L = nn.Linear(2, 3)
print(L.weight.requires_grad)  # True
print(L.weight.grad)           # None: no backward pass yet
print(L.bias.grad)             # None
Source clarification · Parameters are not literal pairs

The lecture describes a weight as a “(weight, gradient)” pair to convey that derivative information can be associated with it. It is a parameter tensor with a .grad attribute, not a Python tuple. For a fresh layer, .grad is normally None until a backward computation produces gradients. Randomly initialized values also do not mean the layer has been trained.

Common Mistakes · Three quick checks

Check the final input dimension, use floating-point inputs compatible with the layer, and remember that nn.Linear does not apply ReLU or tanh. A shape error, a data-type error, and a missing activation are different problems.

Build the source network

Source: §1.1, NeuralNet, a 1 → 20 → 1 network, and its plotted forward pass.

The lecturer’s final example has one input, twenty hidden neurons with tanh, and one affine output. It is a function from ℝ to ℝ.

N(x)=W2tanh(W1x+b1)+b2

W¹ has shape (20, 1), b¹ has 20 entries, W² has shape (1, 20), and b² has one entry. The scalar input expands to 20 hidden values, tanh acts on all 20, and the final affine map combines them into one output.

1 inputx ∈ ℝ
→
20 hidden valuesAf₁, then tanh
→
1 outputAf₂, no final activation
PYTHON · The lecturer’s networkSpacing and comments simplified
class NeuralNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.A1 = nn.Linear(1, 20)
        self.A2 = nn.Linear(20, 1)

    def forward(self, x):
        y = self.A1(x)
        y = torch.tanh(y)
        y = self.A2(y)
        return y

N = NeuralNet()
01

Declare a kind of module

class NeuralNet(nn.Module) defines a new class called NeuralNet, based on PyTorch’s nn.Module. A class is a recipe for objects; N = NeuralNet() creates one instance. Uppercase N is the particular network object.

02

Create its stored layers

def __init__(self) defines the initialization method. self refers to the object being created. super().__init__() initializes the parent module, allowing PyTorch to manage its submodules and parameters. Assigning layers to self.A1 and self.A2 stores and registers them.

03

Describe the forward calculation

def forward(self, x) describes how an input moves through the stored layers. First calculate A1(x), apply torch.tanh elementwise, and then calculate A2(y). return y sends the result back. Calling N(x) runs this forward calculation through the module interface.

Python indentation is part of the syntax: the two methods belong inside the class, and their bodies are indented again. Naming an attribute A1 does not itself compose functions; the order inside forward determines the calculation.

    torch.linspace(-20, 20, 300) returns shape (300,), including both endpoints.

  2. Arrange them as 300 examples with one feature each.

  3. Pass the batch through the model.
    (300, 1) → A1 → (300, 20) → tanh → (300, 20) → A2 → (300, 1)
  4. Draw the 300 input/output pairs.

Common Mistake · A curve is not evidence of learning

A newly constructed network already defines a function, so you can plot it immediately. Its parameters are initialized values. It has not fitted any target data. The source postpones training until after stochastic gradient descent; this guide keeps that same boundary.

A usually nonlinear rule applied after an affine map; here it acts on each entry separately.

Editorial clarifications

These notes make source ambiguities explicit. They do not change the selected scope.

1. Threshold subtraction and bias addition have opposite signs.

Source §1 first writes ReLU(x − b) for a threshold and later ReLU(WX + b) for a bias. Setting b = −θ reconciles the conventions. The worked calculations consistently use additive bias.

2. One weight-vector index appears to be a typo.

In the paragraph after the weighted-vector discussion, the source refers to Wmi−1 for another receiving neuron in layer i. Wmi agrees with the surrounding definitions and matrix rows, and is used here.

3. The final activation follows the source’s formal definition.

The earlier recurrence applies ReLU to each layer. The later formal composition and the PyTorch class end with an affine map. This guide explains the difference and follows the latter convention when assembling the complete networks.

4. nn.Linear is affine when it includes a bias.

The source’s formula Wx + b is correct. Its later description of a general nn.Linear(n, m) as strictly linear needs the qualification b = 0. The bias=False example removes the bias parameter.

5. Batches are a useful input format, not the only valid format.

A single vector with n features also works. In a batch or higher-dimensional input, the last dimension holds the features and is transformed from n to m.

6. Slices are tensors, and parameters are not Python pairs.

Shapes (3,) and (2,) denote one-dimensional tensors. A Parameter stores tensor values and exposes a .grad attribute, normally None before a backward calculation. The source’s “list” and “pair” language is treated as informal explanation.
